Enterprise SASE in the Age of AI

For security engineers and architects who run or review the controls between an organization's people, agents and the internet. SASE products bundle those controls into one vendor service, so this course takes them apart: each module builds one function in a small Python lab, shows the request that gets past it, and teaches the setting that stops it. The second half of each page is a reference you can use in design reviews.

Self-paced. Labs need Python 3 and nothing else. Some modules add an optional real-stack lab, with real proxies and real traffic, that needs more setup. Progress is stored only in this browser.

Course overview

Course briefing

Audience

Security engineers and architects who can read Python and HTTP requests. You do not need to have run a SASE product, and the glossary explains the vocabulary.

Prerequisites

A browser and Python 3. The optional real-stack labs also need the packages they name. No account or production credentials are required.

Current release

One module is published. The others are planned and listed on the roadmap.

Delivery

Self-paced reading, runnable labs, and short knowledge checks.

A companion course

This course looks at traffic from the network. API Security in the Age of AI looks at the same systems from the API. Where a module here meets one there, the lesson links to it.

Assessment and completion

Completion means marking each lesson complete and passing its quick check. The browser records those actions only on this device. Quick checks give immediate feedback, but they are not proctored and do not issue a certificate or training record.
