Glossary

Terms used across the site, in plain language. Each module links here the first time it uses one of these terms.

Base64
A way of writing any bytes using only 64 printable characters, so a file can travel inside a text format such as JSON. It is an encoding, not encryption: anyone can decode it, but a pattern written for the original text will not match the encoded form.
Certificate pinning
An application accepting only a specific certificate or key for a server, instead of any certificate its trust store accepts. A pinned application refuses the certificate a TLS-inspecting gateway presents, so it fails to connect rather than being inspected.
Data loss prevention (DLP)
Controls that look at data leaving an organization and block or record what matches a policy, such as a secret, a card number or a classification label. A DLP scan only finds what its detectors describe, in the encodings it decodes.
Inspection bypass list
The hosts or applications a gateway passes without decrypting, usually because they break under TLS inspection. Every entry is traffic the gateway cannot scan, so each one needs an owner and a reason.
SASE
Secure access service edge. A way of delivering network security as one cloud service: web filtering, data loss prevention, zero trust network access, firewalling and wide area networking, under one policy. It is a delivery model built from separate functions, which is how this course teaches it.
Secure web gateway (SWG)
A proxy that an organization's web traffic passes through on its way to the internet. It decides which destinations are allowed and, with TLS inspection, what content may be sent to them.
TLS inspection
A gateway ending the client's encrypted session, reading the request, and opening its own encrypted session to the destination. The client must trust a certificate authority the organization controls. Without it, a gateway sees the destination host but not the content.
